Использование скрипта по настройке камеры dahua





1\. Устанавливаем python с официального сайта

2\. Устанавливаем зависимости через powershell

&#x20;  pip install requests

&#x20;  pip install selenium webdriver-manager

3\. Настройка:

&#x20;  - Заходим в файл config.py и заполняем данные с камер.

&#x20;    + в переменной USERNAME имя пользователя от веб-морды камеры

&#x20;    + в переменной PASSWORD пароль от камеры  от веб-морды камеры

&#x20;    + в переменной NEW\_GATEWAY\_LAST\_OCTET последнее число шлюза

&#x20;    + в массиве CAMERAS пул IP адресов камер

&#x20;    #### ПРИМЕР:

&#x20;    USERNAME = "admin"

&#x20;    PASSWORD = "admin0000"

&#x20;    NEW\_GATEWAY\_LAST\_OCTET = "254"

&#x20;    CAMERAS = \[

&#x20;    "10.30.0.126", "10.30.0.125", "10.30.0.127"

&#x20;    ]

\- Заходим в файл dahuafixer.py и настраиваем многопоточность

&#x20; + в переменной MAX\_WORKERS указываем сколько камер мы хотим проверять одновременно.

&#x20;   #### ПРИМЕР:

&#x20;   MAX\_WORKERS = 8

4\. Сохраняем и запускаем в powershell.

&#x20;  py .\\dahuafixer.py
